# 터주 포스팅 빌더

터주농산 미팅 내용(스토리 부재, 상세페이지 전문성 부족, 네이버 노출 저조, 1인 기업 시간 부족)을 반영해서 만든 정적 웹앱입니다. 제품 정보를 간단히 입력하면 `사진 → 스토리 → 제품 소개 → 후기/인증 → 상세정보 → 구매유도` 순서(생강차·힘가네 벤치마킹 구조)로 티스토리 HTML 모드에 바로 붙여넣을 수 있는 코드를 만들어줍니다.

## 사용법

1. `index.html`을 브라우저로 엽니다(설치·서버 필요 없음).
2. 상품 카테고리(대추칩 / 대추씨즙 / 건나물 / 명절 선물세트)를 고르면 예시 문구가 채워집니다. 실제 내용으로 필요한 부분만 고쳐 씁니다.
3. 오른쪽 미리보기에서 결과를 확인하고 "티스토리용 HTML 복사"를 눌러 티스토리 글쓰기의 **HTML 모드**에 붙여넣습니다.
4. "메타 설명" 탭의 문구는 본문이 아니라 티스토리 글 설명/네이버 노출용 요약에 따로 붙여넣습니다.
5. 입력 내용은 브라우저에 자동 저장되어 새로고침해도 유지됩니다(다른 기기·다른 사람과는 공유되지 않습니다).

문장을 임의로 지어내지 않고, 입력한 내용만 정해진 구조에 배치합니다 — 스토리와 인증 이력은 실제 사실만 넣어주세요.

## 파일 구성

- `index.html` — 실제 동작하는 앱(입력 폼 + 실시간 미리보기 + HTML/메타 설명 복사)
- `schema/post-schema.json` — 입력 데이터 스키마 정의(향후 자동화·API 연동 시 재사용)

## 다음 단계에서 주면 좋은 것 (우선순위)

1. **대추칩 실사진 + 아이 섭취 영상 캡처본** — hero 사진 자리를 채우는 데 가장 먼저 필요합니다.
2. **아버지 업력 스토리 구체화** — 청와대 납품, 산림조합, 판매왕 이력의 실제 사진/증빙 3~4장.
3. **명절 세트 확정안**(품목·그람·시즌) — 확정되는 즉시 명절 세트용 글을 완성할 수 있습니다.
4. **쿠팡 실제 후기 캡처 + 스마트스토어 링크** — "후기/인증" 섹션과 CTA 버튼에 바로 연결됩니다.
5. **브랜드 리뉴얼 확정 초록색 HEX 코드** — 정해지면 앱 색상과 생성되는 글의 배색을 브랜드에 맞춥니다.

이 중 1~2번(사진·스토리 증빙)이 가장 시급합니다 — 나머지 텍스트는 이미 예시로 채워져 있어 바로 다듬어 쓸 수 있지만, 사진과 실제 증빙 없이는 "신뢰를 주는 사진 한 장"과 "믿을 수 있는 이유" 섹션이 placeholder로 남기 때문입니다.
